# Contributing to apex-confirm

Thank you for your interest in contributing to `apex-confirm`! We welcome bug reports, feature requests, and code contributions from everyone.

## Getting Started
1. **Fork the repository** on GitHub.
2. **Clone your fork** locally.
3. **Install dependencies**: Make sure you have Rust, Soroban CLI, and Node.js installed as detailed in the README.

## Submitting Issues
When creating an issue, please use the provided templates (if applicable) or provide as much context as possible. 
For bug reports, include steps to reproduce, expected behavior, and actual behavior.

## Pull Requests
- Please ensure your commits are small and logical.
- Run `cargo fmt` and `cargo clippy` before submitting your PR.
- Add tests for any new features or bug fixes.
- Your PR should reference the issue it resolves (e.g., "Fixes #123").

Thank you for helping improve `apex-confirm`!
